# Источники логотипов очковых линз

- HOYA: SVG из шапки https://www.hoyavision.com/ — оригинальный чёрный знак.
- ZEISS: https://www.zeiss.com/etc.clientlibs/zeiss-aem-app/jupiter/clientlibs/jupiter-components.app/resources/assets/icons/symbols/zeiss-logo.svg — оригинальный синий знак.
- Synchrony: https://www.synchronylenses.com/ → https://www.exentriq.com/static_exentriqdotcom/images/7f21dfa8-fba8-443f-bbeb-e5b42a574bfd.png — оригинальный серый знак.
- Essilor: https://commons.wikimedia.org/wiki/File:Essilor_logo.png — оригинальный серый знак с фирменной подписью.

Знаки используются для идентификации производителя в карточках. Цвета и пропорции сохранены.
