Первый пакет SEO после перехода на React-витрину

Изменения
1. Meta description карточек: сохраняется непустое description; иначе используется обычный текст descriptionHtml с декодированием HTML-сущностей, удалением разметки и ограничением длины. Если оба источника пусты, используется имя товара без обещания наличия. Одинаковое правило для description и og:description во всех товарных маршрутах.
2. Данные списков больше не заполняют кеш полной карточки. Прямой вход и переход из каталога получают подробности из product.php. Подтверждённый пример: у as_stellest_2_0_crizal_prevencia в списке HTML-описания нет, в полном API оно есть.
3. Названия разделов учитывают родительскую категорию. Исправлены детские оправы, оправы для мальчиков/девочек, детские очковые линзы и подразделы солнцезащитных очков. Метаданные подразделов используют эти же названия; Новокузнецк не наследует петербургское описание. Редакционные тексты цветных и мультифокальных контактных линз сохранены.
4. Production prerender прекращается при ошибках загрузки товара или каталога. Проверка артефакта отклоняет каталог без H1, содержимого main, непустого description, а также страницы с сообщениями об ошибке загрузки.
5. Beta-сборка формирует десять контрольных страниц с проверкой исходного H1 и description, включая MiYOSMART, Stellest и недоступную в списках оправу NOMAD.

Проверка
TypeScript: успешно. Основные тесты: 63/63; unit: 48/48. ESLint: 0 ошибок, 20 существующих предупреждений. Локальная beta-сборка и десять проверок исходного HTML: успешно.

Границы пакета
Robots, sitemap, canonical, noindex и production-маршрутизация не изменяются этим пакетом. Новые проверки содержимого относятся к URL внутри существующего production manifest; они ещё не гарантируют полноту самого списка.

Оставшаяся проблема покрытия
products.php специально исключает CATALOG_AVAILABLE=N. При этом прямой product.php и PHP fallback принимают ACTIVE=Y, включая отсутствующие товары. Проверка Bitrix 29.10.2026: инфоблок 7 — 12 588 активных, из них 2 127 доступных; инфоблок 2 — 11 388 активных, из них 2 070 доступных. Поэтому обход листингов не обеспечивает полный HTML для всех прямых URL. Нельзя исправить это увеличением лимита страниц либо произвольным удалением noindex.

Следующий отдельный пакет: источник полного перечня действительных канонических карточек, стратегия их серверного HTML/обновления и явное поведение для отсутствующих товаров. До этого production fallback остаётся оболочкой для URL вне сборки. Открытие robots Новокузнецка и изменение политики индексации требуют отдельного проверенного артефакта и выпуска.
